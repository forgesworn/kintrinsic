## Remediation pass — 2026-06-27 (post-review fixes)

A deep multi-agent review of the Phases 0–8 core surfaced correctness/security/
durability bugs that the green-but-incomplete test suite missed. All fixed
**test-first**; the full gate is green (**214 tests, 0 ignored**, clippy clean,
`--features real` compiles, vitest 8 + vite build).

**Fixed (with regression tests):**
- **Enforcement (`charter-schedule`/`charterd`):** malformed clause now fail-SAFE
  even with a same-day extension (`enforcer.rs`); DST-correct end-of-day
  (`secs_to_eod` uses the calendar date, not `now+24h`); `Remaining.next_open_secs`
  surfaced (pure layer; the `Remaining → TimeLeftView` D-Bus bridge is Phase-9
  daemon wiring); warn-once re-arms on a rising edge **and across an unbounded
  spell**; freeze target derived from the managed uid (`managed_app_slice(uid)`),
  not a hardcoded `1000`; DST-safe week key; usage **and** the today-only
  extension pool reset on the **clause** tz + weekStart (not the ambient runtime
  tz); `time.extend` today-only EOD uses the **clause** tz (later of schedule/
  budget midnight) via `EnactContext.eod_unix`.
- **Broker/lifecycle (`charterd`):** transient enact failures retry the in-memory
  grant (bounded) instead of going terminal; `exec.allow` enact is resume-safe
  (always (re)asserts trust + launcher); crash-stranded `Enacting` records
  reconcile to `Failed` on boot; an unauthenticated/forged grant stays `Pending`
  (no longer strands the request — hostile-relay liveness); submit persists
  before publishing; `Notify` on enacting/expire.
- **Verify (`charter-verify`):** consumed-id retention covers `exp + SKEW` (closes
  a replay-after-purge window).
- **CLI/GUI:** `ask-for-more` routes `limitHit` to the actually-locked dimension
  via the daemon's lock `reason` (with a guarded seconds fallback that won't
  mislabel a degraded both-zero snapshot, and a budget default on a read error —
  never aborts the ask); a bedtime lock was previously unrelievable. CLI
  `bunker://` validator at parity with `pin_from_connect`; web `TimeLeftView`
  matches the snake_case wire DTO; the GUI lockstep test now reads `contract.rs`
  (real cross-language pin).

**A second adversarial review caught regressions in the first fix round; those
were reverted/corrected before landing:**
- **Reverted M5 (clause forward-skew):** a `now`-based skew gate wrongly rejects
  legitimately-signed clauses on a device whose clock LAGS (dead RTC / pre-NTP),
  silently blocking guardian tightening/revocation. Rollback stays covered by the
  durable monotonic `issuedAt`; a clause freshness bound is deferred (durable
  floor).
- **Reverted M15 (usage monotonic key guard):** stranded the quota when an RTC
  reads a future date and NTP later corrects backward. Clock-manipulation quota
  resets are out of scope here by design — defended by the Phase-9 polkit
  `timedate1` deny-set.
- Kept **M6** (forged/unauthenticated grant stays `Pending`, never strands the
  request): a *deliberate* liveness-over-feedback tradeoff — a malformed grant
  from a buggy guardian gets no terminal feedback until TTL-expiry, but a
  contract-conformant guardian never emits one, and making it terminal would
  reopen the hostile-relay denial-of-approval.
- **`spec/contract.md`:** added the **Device-broker transport (v1)** section
  documenting the frozen kinds / signed-inner-event gift-wrap / REQUEST·GRANT·
  CLAUSE envelopes / `bunker://` grammar / audit vocabulary, with the genuine
  cross-repo decisions tagged **[decide]** for the Signet team. (signet-app was
  **not** modified.)

**Deferred (documented, out of anti-casual v1 scope):**
- `time.extend` fully-durable-before-ack snapshot (M14) — needs a persistence
  port threaded into the enactor; today it persists on the immediately-following
  re-eval tick (one-tick window).
- A clause freshness/age floor (M5) — fully deferred to a **durable** issuedAt
  floor. A stateless `now`-based bound (forward or backward) was tried and
  reverted: it false-rejects legitimate clauses on a device with a wrong clock,
  which the fail-safe-offline model must tolerate. The durable monotonic
  `issuedAt` already protects every clause after the first.
- Transport cursor/jitter/DoS-cap hardening (M23–M25) — latent until the real
  relay replaces the mock (Phase 9 transport work).
- The device-audit ↔ signet-app audit-feed reconciliation and the `bunker://`
  `kind=charter` placement — cross-repo **[decide]** items in `contract.md`.
